# PRIDE CRUD 프로젝트

## 📌 프로젝트 소개
이 저장소는 **CRUD(Create, Read, Update, Delete)** 기능을 중심으로 한 협업 학습 및 실습을 위한 리포지토리입니다.  
팀원 간의 협업 흐름을 이해하고, 실제 개발 환경에서의 작업 방식(이슈 관리, 브랜치 전략, 코드 리뷰 등)을 경험하는 것을 목표로 합니다.

---

## 🎯 목표
- CRUD 기능 구현을 통한 기본적인 웹 애플리케이션 구조 이해
- Git 기반 협업 프로세스 경험
- 코드 리뷰 및 커뮤니케이션 능력 향상
- REST API 기반 데이터 처리 흐름 학습

---

## 🛠️ 주요 기능
- **Create**: 게시글 생성
- **Read**: 게시글 목록 조회 및 상세 조회
- **Update**: 게시글 수정
- **Delete**: 게시글 삭제

---

## 🤝 협업 방식

### 1. 작업 흐름
1. 이슈 생성
2. 브랜치 생성 (`feature/이슈번호-기능명`)
3. 기능 개발
4. 커밋 및 푸시
5. Pull Request 생성
6. 코드 리뷰 후 병합

---

### 2. 브랜치 전략
- `main`: 배포 가능한 안정 버전
- `develop`: 개발 통합 브랜치
- `feature/*`: 기능 개발 브랜치

---

### 3. 커밋 컨벤션 (예시)
- `feat`: 기능 추가
- `fix`: 버그 수정
- `refactor`: 코드 리팩토링
- `docs`: 문서 수정

---
